[web] framework integrations and dashboard

Install with python -m pip install "netguard-threat-monitor[web]". This extra provides FastAPI, Django, Uvicorn, HTTPX, and multipart support. It includes the FastAPI embedded dashboard, standalone multi-project dashboard, proxy, and web alert integrations.

Core SDK calls used by web apps

SymbolWhat it doesTypical use
NetGuard(config=None, **kwargs)Loads the bundled model and creates the rules, flow aggregator, alert manager, and runtime state. With keyword settings, it reads the remaining NETGUARD_* variables.guard = NetGuard(project_id="orders", auth_username=..., auth_password=...)
NetGuardConfig.from_env(**overrides)Loads supported environment settings and lets explicit values override them.config = NetGuardConfig.from_env(project_id="orders")
config.validate_auth()Raises ValueError unless dashboard username/password or an API key is configured.Usually called by NetGuard during construction.
smtp_configured, resend_configured, email_configuredRead-only properties reporting whether the selected provider has the required sender, recipient, and credentials.Use for configuration diagnostics.
setup_netguard(app, guard, mount_dashboard=True)Attaches FastAPI request and lifespan middleware; by default, mounts the authenticated dashboard at the configured path.Call once after creating the FastAPI app and guard.
NetGuardMiddleware(app, guard)ASGI middleware that measures request metadata, evaluates rules, and sends data to the guard.Prefer setup_netguard, which also attaches lifecycle handling.
NetGuardDjangoMiddleware(get_response, guard=None)Django middleware that records each request/response and returns 403 for an IP already blocked in that process.Add "netguard.integrations.django.NetGuardDjangoMiddleware" to Django’s MIDDLEWARE.
create_dashboard_app(guard)Creates the authenticated Starlette dashboard app for a guard. setup_netguard calls it when mounting the embedded dashboard.Use directly only when you need to mount the dashboard yourself.
create_dashboard_server_app(username, password, api_key="", storage_path=...)Creates the standalone authenticated dashboard that receives events and telemetry from several services; persists project data in SQLite.CLI equivalent: netguard serve.
create_proxy_app(target, guard)Creates an HTTP reverse proxy that forwards requests through NetGuard monitoring.CLI equivalent: netguard proxy.

FASTAPI · LOAD CONFIGURATION FROM RENDER OR A SECRET MANAGER 
from fastapi import FastAPI
from netguard import NetGuard, NetGuardConfig
from netguard.integrations.fastapi import setup_netguard

app = FastAPI()
config = NetGuardConfig.from_env(project_id="orders-api")
guard = NetGuard(config=config)
setup_netguard(app, guard)

@app.get("/")

FastAPI mounts the embedded dashboard. Django middleware does not mount that dashboard; use a separate central dashboard if you want a browser dashboard for Django traffic.

[train] data, models, evaluation, and PCAP

Install with python -m pip install "netguard-threat-monitor[train]". The extra includes pandas, imbalanced-learn, SHAP, Optuna, plotting tools, Streamlit, and Scapy. Current built-in functions use pandas and plotting libraries for training/evaluation, and Scapy for PCAP/live packet commands. SHAP, Optuna, Streamlit, and imbalanced-learn are installed by the extra but are not currently invoked by the package’s built-in CLI commands.

DATAThe CICIDS2017 dataset is not bundled. Download data you are licensed to use, keep it out of public repositories unless its terms allow publication, and check labels/columns before training. Training overwrites model artifacts in the selected model directory.

[flask] extension API

Install with python -m pip install "netguard-threat-monitor[flask]". The Flask extension is a separate legacy integration based on AppTrafficMonitor; its behavior and dashboard differ from the canonical FastAPI SDK.

NetGuardFlask

CONSTRUCTOR AND APP FACTORY PATTERN 
from flask import Flask
from netguard.integrations.flask import NetGuardFlask

app = Flask(__name__)
netguard = NetGuardFlask(
    app=None,
    dashboard=True,
    mount_path="/_netguard",
    alert_webhook=None,
    alert_log_file="alerts.log",
    block_attacks=False,
    block_duration_seconds=300.0,
)
netguard.init_app(app)
Argument / methodBehavior
app=NoneOptionally bind immediately. Use init_app(app) later for an application factory.
dashboard=True, mount_path="/_netguard"Enables the legacy dashboard and its API endpoints at the configured path.
alert_webhook=None, alert_log_file=NoneOptionally send alerts to a webhook and write JSONL alert records.
block_attacks=False, block_duration_seconds=300.0When enabled, this legacy monitor automatically blocks matched clients above its confidence threshold. This differs from the canonical FastAPI SDK’s manual-block default.
engine=NoneOptional custom DetectionEngine; otherwise the bundled model is loaded.
init_app(app)Registers Flask before/after request hooks and, if enabled, dashboard endpoints.
netguard.monitorUnderlying AppTrafficMonitor, including analyze_request, get_stats, block_ip, unblock_ip, is_ip_blocked, and get_blocked_ips.

Security note: the legacy Flask dashboard/API endpoints shown here do not add authentication themselves. Do not expose them publicly as-is. Disable the dashboard with dashboard=False, or protect the mount path at your application/authentication or trusted reverse-proxy layer.

Deploy this documentation website

This site is plain HTML, CSS, and JavaScript. It has no build step, server-side runtime, or external asset dependency. Deploy the contents of the docs/ directory as a static site.

Render Static Site

01 Push the repository containing this docs/ directory to GitHub.

02 In Render choose New → Static Site, connect the repository and branch.

03 Set the publish directory to docs. No build output is generated; use an empty build command if accepted, otherwise echo "Static docs; no build required".

04 Deploy, open the generated site URL, and check that the homepage, styles, scripts, API reference, and prompt page load.

GitHub Pages or Netlify

For GitHub Pages, choose the branch containing this repository and the /docs folder as the publishing source. For Netlify, connect the repository, set the publish directory to docs, and leave the build command empty. Because navigation uses relative paths, the pages work from a subpath as well as a domain root.
